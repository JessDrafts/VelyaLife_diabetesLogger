# VelyaLife

This project was made for the Software engineering course of the University of Verona year 2024/2025. The version presented here is an upgraded version of the original one. for the original one read This site was built using [RELAZIONE INGEGNERIA DEL SOFTWARE_V1.pdf]([https://pages.github.com/](https://github.com/JessDrafts/VelyaLife_diabetesLogger/blob/main/documentation/RELAZIONE%20INGEGNERIA%20DEL%20SOFTWARE_V1.pdf)
This is a system made for diabetes patients.

# ⚙️Features 
* Admin can create/remove users
* Admin can see doctor's activities
* Patients can measure blood sugar level, add symptoms, other medical conditions
* Patients can view their therapy and medical informations.
* Patients get a remainder to follow their therapy.
* Doctors can view their patient's details.
* Both doctors and patient cha download their medical chart.
* Doctors can add, remove and edit patient's therapy.
* Doctors receive alerts in case of medical emergency.
* Every user receives an email in case of profile update and/or elimination.

## 📑Requirements
* Any OS works
* Java IDE: for this project intellij was used. The original project was made using eclipse.
* Database management system: SQLite was used for both this version and the original version.
* Email provider for the admin (use an external file since they are sensible information)

## 💻Run the project  
Download the repo and unzip it.
Set up your desired database and email service. After configuring the IDE you selected, copy the project there and open the file named Launcher and click run. If everything works you’ll see the home page.
